# 🌫️ 아두이노 미세먼지 측정기

아두이노와 광학식 미세먼지 센서로 공기 중 먼지 농도를 1초마다 측정해
시리얼 모니터에 출력하는 프로젝트입니다.

## 🔧 사용 부품

| 부품 | 수량 |
|---|---|
| Arduino Uno | 1 |
| 미세먼지 센서 (Sharp GP2Y1010AU0F) | 1 |
| 저항 150Ω | 1 |
| 전해 커패시터 220µF | 1 |
| 브레드보드, 점퍼선 | - |

## 🔌 회로 연결

| 센서 핀 | 아두이노 |
|---|---|
| V-LED | 150Ω 저항 → 5V (220µF 커패시터 → GND) |
| LED-GND | GND |
| LED | D12 |
| S-GND | GND |
| Vo | A0 |
| Vcc | 5V |

## ⚙️ 동작 원리

1. 센서 내부 적외선 LED를 켠다 (D12 → LOW)
2. 280µs 뒤 먼지에 반사된 빛의 양을 아날로그 전압으로 읽는다 (A0)
3. LED를 끄고 남은 주기(약 10ms)를 기다린다
4. 읽은 값을 전압으로 바꾸고, 전압을 먼지 농도로 변환한다

```
전압(V)     = 아날로그값 × 5.0 / 1023
먼지 농도   = (전압 − 0.5) / 0.005   [µg/m³]
```

센서 데이터시트의 타이밍(펄스 주기 10ms, 측정 시점 0.28ms)을 그대로 따랐습니다.

## ▶️ 실행 방법

1. 위 표대로 회로를 연결한다
2. Arduino IDE에서 `dustSensor.ino`를 업로드한다
3. 시리얼 모니터를 9600bps로 열면 `dust=값`이 1초마다 출력된다
