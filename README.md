# 아두이노 미세먼지 측정

아두이노에 미세먼지 센서(GP2Y1010AU0F)를 연결해서 먼지 농도를 1초마다 시리얼 모니터에 출력해 봤다.

## 부품

- Arduino Uno
- 미세먼지 센서 GP2Y1010AU0F
- 150Ω 저항, 220µF 커패시터
- 브레드보드, 점퍼선

## 연결

- V-LED: 150Ω 저항 거쳐서 5V, 220µF 커패시터로 GND
- LED-GND, S-GND: GND
- LED: D12
- Vo: A0
- Vcc: 5V

## 측정 방법

센서 안의 LED를 켜고 0.28ms 뒤에 A0 값을 읽는다. 데이터시트에 나온 타이밍(주기 10ms)을 그대로 썼다.
읽은 값을 전압으로 바꾼 다음 아래 식으로 농도를 계산했다.

```
전압 = 측정값 * 5.0 / 1023
농도(µg/m³) = (전압 - 0.5) / 0.005
```

한 번만 재면 값이 많이 튀어서 10번 재서 평균을 내고, 공기가 깨끗할 때 음수가 나와서 0 아래는 0으로 처리했다.

## 실행

`dustSensor.ino`를 업로드하고 시리얼 모니터를 9600으로 열면 `dust=값` 형태로 나온다.
